## Projects

<table>
<tr>
<td>

### 🚁 Autonomous Drone Systems

YOLO-based object detection and collision avoidance for autonomous drones using Intel RealSense depth cameras. Validated with real-world flight experiments at Fraunhofer IVI.

### 🦾 Image Segmentation for Robotic Grasping

SAM-2 segmentation pipeline in Python, PyTorch and OpenCV enabling robots to identify and grasp objects from visual input.

### ⚡ NVIDIA Isaac Sim

CAD-to-URDF workflows, multibody dynamic simulation, and autonomous indoor navigation for custom assistive robots with ROS 2 and Nav2 integration.

### 🤖 Robot Control Stack

Forked and extended sim-to-real framework for VLA models and reinforcement learning agents using MuJoCo Gymnasium wrappers.

### 🧠 Machine Learning

Research notebooks covering reinforcement learning, deep learning and imitation learning experiments.

### 🔧 Hardware Prototyping — LeRobot SO-101 & VLA Integration

Integrated SO-101 arm, ZED Mini and Hugging Face VLA models (ACT, X-VLA, Pi0, GR00T) for perception-driven manipulation.
